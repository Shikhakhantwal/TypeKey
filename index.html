Speed vs Accuracy Mode

Two distinct training mindsets powered by the same unified typing engine

⚡

Speed Mode

Velocity First

Focus entirely on typing cadence, tempo, and high words-per-minute throughput. Designed for experienced typists training for maximum raw typing speed.

  • Prominent UI: WPM and Live Timer highlighted with larger visual indicators.
  • Rhythm Training: Encourages steady forward movement.
  • Objective: Reach personal best WPM milestones.
🎯

Accuracy Mode

Precision First

Focus on error-free typing, disciplined keystrokes, and deliberate finger placement. Mistakes are highlighted sharply to discourage reckless speed and instill proper muscle memory.

  • Prominent UI: Accuracy percentage and Mistake counters are magnified.
  • Muscle Memory: Teaches patience and clean finger movements.
  • Objective: Maintain a 98%+ accuracy rating on every session.

About TypeKey

College & Solo Project • Clean Architecture • Pure Client-Side

Project Mission

"TypeKey is a simple typing practice and assessment platform designed to help users improve typing speed, accuracy, and keyboard skills."

Built as a transparent, responsive solo project, TypeKey demonstrates how standard browser technologies can power sophisticated real-time text analysis, algorithmic mistake tracking, and user skill assessment without requiring heavy frameworks, external AI APIs, or remote databases.

Core Technologies Used

🌐 HTML5 Semantic Markup 🎨 Modern CSS3 & Flexbox / Grid ⚡ Pure Vanilla JavaScript (ES6+) 💾 LocalStorage API for Persistence 🔒 100% Offline Capable

Standard Math Formulas

All calculations are performed locally in real time:

Words Per Minute (WPM): WPM = (Correct Characters ÷ 5) ÷ (Elapsed Minutes) * Standard typing convention: 5 characters = 1 word.
Accuracy Percentage: Accuracy = (Correct Characters ÷ Total Typed Characters) × 100 * Division-by-zero handled safely when starting.
Performance Score: Score = Math.round(WPM × (Accuracy ÷ 100)) * Transparent metric balancing speed and precision.
